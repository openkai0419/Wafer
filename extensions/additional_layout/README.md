## Additional Layout Extension

Advanced grid layout algorithms.

### Layouts
- **MultiSpan Grid** — Variable-span cells (up to 3×3) for emphasis on larger items
- **MultiSpan Tiling** — Tiling variant of multi-span layout
- **Justified** — Dynamic-programming row balancing for even visual weight
- **Partition (Aspect)** — Binary partitioning weighted by aspect ratio for organic arrangements
