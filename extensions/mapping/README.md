# Mapping

Lays out the selected files on a 2D map by how similar their tags, metadata, numbers, or colors are, and groups them.

- Grid: right-click → Mapping → Set / Add
- Map: drag to select, Ctrl to add. Copy, cut and other file commands work like in the Grid.
- Mapping Space: choose keys and retrain the database-wide map. Enable the Mapping parser per database in Plugin Manager; it keeps new files placed in the background. Quick Train checks the current settings on random files without saving.
- Folders compares paths by their folders (file name ignored).
- Files inside archives are not precomputed; use Live mode for them.
