Prototype summary

- Purpose: Test command invocation via context menu, mouse events, and keyboard shortcuts using PySide6.
- Files (in use by demo_app):
  - prototypes/menu_demo.py: CmdMenu, FileMenu, PathMenu, AllMenu
  - prototypes/shortcutmanager.py: QShortcut によるショートカット管理
  - prototypes/mouseeventmanager.py: マウス入力のバインド/ディスパッチ
  - prototypes/commandbase.py: コマンド/メニュー基盤（チェック可能項目対応）
  - prototypes/demo_app.py: 実行用ウィンドウ・右クリックメニュー・バインディング編集
- Behavior:
  - Right-click opens CmdMenu as base and appends FileMenu and PathMenu.
  - Mouse bindings call commands via MouseEventManager; per-widget configurable.
  - Shortcut bindings call commands via QShortcut; per-widget configurable.
  - Edit menus: one for mouse, one for shortcut; each lets you select target widget and adjust mappings.
- Notes:
  - Command contents are print-only per requirement.
  - Bindings are in-memory and not persisted.
  - prototypes/commandbase.py imports are adjusted to absolute `source.*` for standalone run.
  - To run: from repo root, use `python -m prototypes.demo_app` (Windows cmd). Ensure `PySide6` is installed.
